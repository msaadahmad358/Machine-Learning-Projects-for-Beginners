**Classification of Text Documents using Naive Bayes**
Classifying text documents using Naive-Bayes especially is a famous technique to use in achine learning while processing text and make a model to predict something accurately. I have done this using following steps:

Step 1 - Importing libraries
Step 2 - Loading the dataset
Step 3 - Splitting the Data
Step 4 - Text Processing > Converting text to numeric features
Step 5 - Training the Naive Bayes classifier
Step 6 - making predictions
Step 7 - Evaluating the model
Step 8 - Prediction on unseen data

Mainly, two concepts are used in this project should be focused on them are:
(1) Count Vectorizer: convert text data into numerical features using word counts
(2) MultinomialNB: the naive bayes classifier for multinomial data is ideal for text classification.
