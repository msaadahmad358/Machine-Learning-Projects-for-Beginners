**Text Detection and Extraction using OpenCV and OCR**
I have done a project which can detect text in image and then extract it into a string text as output. It was completed using opencv and tesseract. I have followed 7 steps to do this mentioned below:

Step 1 - import libraries
Step 2 - loading input image using cv2.imread
Step 3 - convert image into grayscale
Step 4 - display and save original image
Step 5 - extract text from image
Step 6 - draw bounding boxes around text
Step 7 - show image with bounding boxes

This is really a simple project but an interested one to do and see the results.
