**Count number of Faces using Python - OpenCV**
Using image processing this project detect and count the number of faces. It is not supposed to get all the features of face but objective is to obtain the bounding box through some methods. This is completed in 3 steps only for clear understanding and getting the sutructure correctly mentioned below:

Step 1 - import libraries (cv2, numpy, dlib)
Step 2 - opening default camera to capture the image
Step 3 - a looped script to count the no. of faces continuously
Step 4 - Terminate the loop and clear window.

This is a basic python project using OpenCV but mandatory to learn for understanding of how things work and processed in this environment, mainly in terms of image processing.
