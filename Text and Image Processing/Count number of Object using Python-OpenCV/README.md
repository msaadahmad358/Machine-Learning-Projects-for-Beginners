**Count number of Object using Python-OpenCV**
In this basic project, 4 libraries were imported cv2, matplotlib.pyplot, numpy and os.
This model is detecting objects in image and count numbers of object.

Code is written in steps mentioned below:
Step 1 - reading image and make it gray
Step 2 - blurring image
Step 3 - detect edges of objects using canny algorithm
Step 4 - connecting edges and ignore inside or extra ones
Step 5 - convert into RGB from BGR
Step 6 - printing the output result in integer number.
